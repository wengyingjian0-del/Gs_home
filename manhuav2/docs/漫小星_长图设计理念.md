# 温柔导引

“温柔导引”把复杂操作收束为一条安静、明确的阅读路径。空间不是装饰，而是节奏：每个步骤拥有足够呼吸，编号、说明与真实画面形成稳定的三段关系，让第一次接触的人不需要寻找入口，也不会被信息压迫。

色彩来自产品本身的暖白、珊瑚粉与嫩绿色。颜色只承担区分与提示，不制造喧闹；成功、等待和问题分别用绿色、金色和柔和红色表达。所有色块经过克制校准，保持亲和力与业务材料所需的专业感。

真实截图是视觉证据，也是画面的主体。截图保持原始比例、原始文字和原始操作状态，置于细致的圆角边框与轻微阴影中。每一处裁切都应像经过长时间推敲，既让关键按钮清晰，又不把界面伪装成不存在的新页面。

编号与纵向箭头建立连续节拍，使视线自然从准备、操作、等待走到结果。说明文字只保留完成任务所需的一句话，标题负责定位，状态标签负责确认。层级必须经过大师级的反复打磨，让用户在数秒内知道“现在在哪、接下来点什么、什么时候算完成”。

最终作品应像一本被精心压缩成单页的操作手册：细节严谨、边界整洁、字距与留白经过痛苦而准确的校正。它不依靠额外插画制造热闹，而以真实画面、清晰顺序和可靠信息体现专业制作的耐心。
