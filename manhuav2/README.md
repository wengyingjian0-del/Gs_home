# 画芽 · 儿童漫画 AI 生图工具

面向中国大陆 8—12 岁儿童及家长的手机端 H5/PWA。当前实现聚焦 MVP：创建固定角色、引导式场景选择、万相四图生成、百炼视觉评选、单图结果与历史版本数据结构。

## 本地运行

要求 Node.js 22.13 或更高版本。

Windows 当前机器可直接在 PowerShell 中运行，无需配置 npm：

```powershell
.\start-dev.cmd
```

脚本会自动打开 `http://localhost:3000`，启动期间请保持终端窗口开启。

已自行安装 Node.js 和 pnpm 时也可以使用：

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:3000`。未配置模型服务时会明确报错，不会调用外部接口，也不会用占位图冒充生成结果。

## 服务端配置

复制 `.env.example` 为本地环境文件并填写新密钥。不要使用曾在聊天、日志或代码中出现过的密钥。

- `DASHSCOPE_API_KEY`：百炼华北 2（北京）API Key
- `DASHSCOPE_WORKSPACE_ID`：可选；留空时使用百炼北京公共域名
- `BAILIAN_VISION_MODEL`：可选；默认使用 `qwen3-vl-plus`

所有配置只在服务端读取。浏览器只提交角色、场景选择和一条内部历史图片标识，不接受用户上传图片或外部图片地址。

## 生成管线

1. 输入长度、儿童不适内容和个人信息初筛。
2. 百炼视觉模型结合角色卡、所选历史图和上一轮结构化上下文，改写本轮生图请求并划分修改项/锁定项。
3. 改写结果再次经过儿童安全检查。
4. `wan2.7-image` 先生成 2 张初稿，视觉模型自动选择较好的一张。
5. 系统以入选初稿为参考生成 1 张定向精修图，并重新比较；只有精修未达门槛时才触发最后 1 张补救图。
6. 儿童端只收到最终审核通过的一张；配置 R2 后，管理员可在受保护的 `/admin` 查看完整优化链路。
7. 局部修改时，后端只允许引用一张系统已保存的历史图片。

管理员入口需要额外配置服务端环境变量 `ADMIN_ACCESS_TOKEN`。未配置时 `/admin` 保持锁定，不展示候选图片。

## 数据与发布

- D1：家长、儿童身份、角色卡、作品、版本和生成任务。
- R2：角色参考图和正式作品图片。
- `.openai/hosting.json` 已声明 `DB` 与 `ARTWORKS` 绑定。
- SQL 迁移位于 `drizzle/`。
